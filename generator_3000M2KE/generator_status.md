# Генератор PM-AGR-3000M2KE — стан і рішення (оновлено 2026-11-09)

## Прошивка
- Плата: WeAct ESP32C6-MINI N4, окрема від SITE. Файл generator_3000M2KE.ino, версія 1.3.
- Ядро esp32 3.x, Tools → USB CDC On Boot = Enabled, Partition Scheme = Default 4MB with spiffs (потрібна для OTA). Бібліотеки: OneWireNg (не OneWire від Paul Stoffregen — не компілюється під C6), DallasTemperature.
- Протокол із SITE: PROTOCOL_GEN_SITE.md v1.3 (UART 9600, кадри $тіло*CRC, HB з DAY/NIGHT, секундами до зміни і прогнозом хвилин зарядки; ST — 22 поля).
- SITE: START,AUTO — лише власне рішення SITE; команди оператора з HOME пересилати як START,MANUAL.

## Wi-Fi на місці (v1.3)
- Точка доступу GEN-3000, сторінка http://192.168.4.1. Пароль Wi-Fi і PIN для дій — у прошивці (не дублюються тут).
- Вмикається: кнопка BOOT 2 с, `wifi on` у Serial, CMD,WIFI,ON від SITE. Вимикається сама через 10 хв без підключень, якщо двигун не працює.
- Сторінка: стан, дії (PIN), паливо, сервіс, налаштування, журнал останніх 30 подій, оновлення прошивки (.bin, лише коли генератор стоїть). 5 невірних PIN — блок 5 хв.
- Генератор у ямі: сигнал Wi-Fi крізь кришку ще не перевірено.

## Піни генераторної C6
| GPIO | Функція |
|---|---|
| 20 | IN1 СТОП (HIGH = запалювання дозволене, реле NC на синій–зелений замка) |
| 21 | IN2 СТАРТ (білий–чорний замка) |
| 22 | IN3 SSR (230 В на 2 розетки зарядних) |
| 23 | IN4 насос EP-500-0 |
| 19 | детекція 230 В: MY3 контакт 4, 7 на GND (до автомата і SSR) |
| 18 | PWM серво чока DS3115MG |
| 0 | затвор IRLZ44N — живлення серво |
| 1 | АЦП дільник АКБ 100k/18k |
| 2 | АЦП датчик палива, підтяжка 470 Ом від GPIO 3 |
| 14 | DS18B20 (АКБ + двигун на одній шині, 4,7 кОм до 3V3) |
| 6 / 7 | UART TX / RX до SITE через ADUM1201 біля SITE |
| 9 | кнопка BOOT (лише читання під час роботи) — увімкнути Wi-Fi |
Плата живиться 5 В на пін 5V. Модуль реле HW-280 4×12 В, перемички на H.

## Калібрування
- Чок: OPEN_US = 1280, CLOSED_US = 1820 (після перевстановлення серво 2026-11-08).
- АКБ: K = 6,616.
- Паливо (0–190 Ом, 5 сходинок): пороги 155 / 400 / 600 / 810 мВ, понад 2500 мВ — обрив. Бак 15 л.
- DS18B20 АКБ: 28951222000000CC. Датчик двигуна визначається автоматично (будь-який інший на шині); місце — картер біля горловини масла (плаский майданчик з номером, на термогерметик) або болт на лапі картера. Не чіпати: гайку датчика масла, пробку зливу. Поріг «теплий» 40 °C — уточнити замірами охолодження.

## Логіка (узгоджено)
- start вночі не заводиться; start dark — примусово, без work максимум 30 хв. Без HB час невідомий → лише start dark.
- Дозаправки перед запуском немає (з v1.3).
- Чок: на холодному двигуні закритий; теплий (датчик ≥ 40 °C або < 20 хв після зупинки) — без чока; 2-га і 3-тя спроби завжди з чоком. Відкривається одразу після запуску: < 0 °C 30 с, 0–10 °C 15 с, > 10 °C 5 с. Заглух у перші 15 с — повтор, чок удвічі повільніше.
- Зупинка: STOP від SITE завжди; 5 год; work H:MM (до 8 год від запуску); ніч (крім dark і work); без зв'язку — прогноз зарядки з останнього HB + 25 хв.
- Паливо: низький рівень не глушить, лише попередження.
- Дозаправка після роботи: після AUTO — через 30 хв до повного (2 хв, якщо заглух без палива); після ручної (MANUAL, DARK, SERVICE) — лише за `pump after [N]`; `pump after off` скасовує і для AUTO; після аварії — ні. Новий запуск під час очікування переносить дозаправку на кінець нової роботи. Запланована дозаправка зберігається в NVS і переживає перезавантаження. Рівень не росте 5 хв — CANISTER, запуск усе одно.
- Заглух, а паливо є → аварія STALL (ймовірно датчик масла), блок до reset.

## Апаратні нотатки
- Діод 1N4007 на реле стартера: катод на маленьку клему керування (червоний дріт), анод на масу. Без нього згорів канал 2 старого модуля.
- Біле обплетення з-під маховика — зарядна обмотка, від'єднана і заізольована (Li-ion 3S12P заряджається окремим зарядним 12,6 В).
- Кнопка маси 3-позиційна (ручний / ESP); у режимі ESP ключ не глушить; середнє положення без маси — не лишати. Планується заміна на MTS-202 DPDT ON-ON з сигналом режиму на ESP.
